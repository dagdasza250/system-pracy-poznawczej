# Kanoniczna mapa programu SPP

Ta mapa zastępuje wcześniejsze kolejności, w których pełna architektura produktu lub AI mogły poprzedzać dowód wartości.

## Nadrzędna kolejność

**Research → decyzja wartości → Product → badanie AI → beta i replikacja → produkcja**

## Research

- **R0** — Formalny baseline v0.5.1
- **R1** — Minimalny kontrakt wartości
- **R2** — Minimalna ontologia eksperymentalna
- **R3** — Użyteczność ścieżki badawczej
- **R4** — Stabilność eksperymentalna
- **R5** — Zamrożony protokół
- **R6** — Walidacja poznawcza 02: indywidualny pilotaż porównawczy
- **D0** — Bramka wartości: STOP / INCONCLUSIVE / RETURN / SIMPLIFY / GO NARROW / GO

## Product — tylko po GO

- **P0** — Specyfikacja oparta na wyniku
- **P1** — Pełne UX
- **P2** — Architektura + bezpieczeństwo
- **P3** — Dane i migracje
- **P4** — Produkcyjny import
- **P5** — Ręczny rdzeń
- **P6** — Audyt i pochodzenie
- **P7** — Hardening

## AI — dopiero po wykazaniu wartości ręcznej

- **A0** — Eksperymenty pojedynczych operacji AI
- **A1** — Porównanie AI z ręcznym SPP
- **A2** — Human-in-the-loop

## Beta i replikacja

- **B0** — Beta zamknięta
- **B1** — Walidacja wieloosobowa
- **B2** — Granice zastosowania

## PROD

Wdrożenie, monitoring, rollback, kontrola kosztów AI, regresja semantyczna i ponowna walidacja po zmianie modelu, promptu lub ontologii.

## Zasada programu

Minimalny instrument → eksperyment wartości → decyzja → dopiero wtedy produkt.
