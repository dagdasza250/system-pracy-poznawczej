# SPP — Program Status Pointer

Ten plik **nie jest już niezależnym źródłem aktualnego stanu programu**.

Od ustanowienia **SPP PROJECT CONTROL v1** jedynym kanonicznym źródłem stanu operacyjnego jest:

➡️ [`../PROJECT_CONTROL.md`](../PROJECT_CONTROL.md)

## Reguła

- zamrożone artefakty badawcze = prawda merytoryczna;
- `PROJECT_CONTROL.md` = prawda o `STATE_NOW`;
- ten plik istnieje wyłącznie jako kompatybilny wskaźnik dla wcześniejszych odwołań.

Nie aktualizować tutaj osobnej kopii statusów etapów.
